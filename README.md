## How to Publish

To publish this website using GitHub Pages:

1. Go to the repository settings
2. Navigate to the "Pages" section
3. Set the source to the `main` branch and `/docs` folder
4. The site will be published automatically
5. (Optional) Add a custom domain via Pages settings or CNAME file
