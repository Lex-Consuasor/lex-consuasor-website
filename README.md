# lex-consuasor-website

Static GitHub Pages site for Lex Consuasor.

This repository contains a lightweight static site in the `docs/` folder. The content was adapted from:

- https://lex-consuasor.grexa.site/
- https://www.facebook.com/lexConsuasor/

How to publish

1. In the repository settings > Pages, set the source to the `main` branch and the `/docs` folder. The site will then be published by GitHub Pages.
2. Optionally add a custom domain via the Pages settings or a CNAME file.

Files created

- docs/index.html — main site
- docs/styles.css — basic styling
